# 核弹

顾名思义，核弹是一种核武器。

# 合成

<recipe id="anvilcraftextrapower:nuclear_bomb"/>

# 用途

- (1). 与<ref item="anvilcraftextrapower:nuclear_collector"/>组合构成核反应堆
- (2). 作为铁砧使用~~展示品味~~
- (3). 当从高处下落损坏时或下落失败时，产生核爆
- (4). 核爆会熔炼爆炸边沿方块，并熔炼爆炸范围的所有矿物（变为掉落物，如果产出为方块则以方块的形式出现）
-      这样你可以方便的进行大范围的矿物开采
